# たてモニ
### ── iPadを縦のサブモニターにする

Sidecarで接続したiPadは、いつも横向きの画面にしかなりません。
「たてモニ」は、そのiPadを**縦長のサブモニター**として使えるようにする、
Mac用の無料アプリです。

メニューバーに常駐して、メニューから「縦」を選ぶだけで使えます。

---

## ダウンロード（プログラムの知識は要りません）

1. このページ上部の **[Releases]**（リリース）を開きます
2. 一番上にある **`たてモニ.app.zip`** をクリックしてダウンロードします
3. ダウンロードした zip をダブルクリックして開くと、`たてモニ.app` が出てきます
4. `たてモニ.app` を **アプリケーション フォルダ** にドラッグします
5. `たてモニ.app` をダブルクリックして開きます

**★ここだけ注意★**
初めて開くとき、「Appleで確認できないため開けません」という
警告が出ることがあります。これはウイルスではなく、個人が無料で
配っているアプリによくあることです。対処は下の
「[初回に警告が出たとき](#初回に警告が出たとき)」を見てください。

> ソースコードやビルド用のスクリプトは、この下の「開発者向け」の
> 章にまとめてあります。**普通に使うだけなら、そちらは読まなくて大丈夫です。**

---

## これは何をしているアプリ？

1. 縦長の「仮想ディスプレイ（器）」を1枚こしらえます
2. 器の中身を画面キャプチャで撮ります
3. その映像を90度倒して、iPadの画面の上に
   枠なし・最前面・真っ黒の窓で貼り付けます

**画面を回転させているのではなく、回した絵を描いて見せています。**
そのため、次の2点は仕組み上どうしても直せません。

- システム設定の「ディスプレイ」の一覧に、画面が1つ多く見えます（器の分）
- iPadの画面を直接指で触っても反応しません（あくまで映像です）

---

## 動作条件

「MacとiPadでSidecarが使えれば、使えます。」

- macOS 12.3 以降（目安）
- Apple Silicon Mac / Intel Mac 両対応でビルドしています
  （★Apple Silicon Macでの動作は実機で確認済みです。Intel Macでの
  動作は、手元にIntel Macが無いため実機で確認できていません★。
  もしIntel Macで試して動かなかった場合は、Issueで教えてください）
- iPadOS 26.6 で動作確認しています（iPad mini 第6世代）

---

## 使い方

1. `たてモニ.app` を開くと、メニューバーにアイコンが出ます
2. iPadとSidecarで接続します（横向きのまま）
3. メニューバーのアイコンをクリックし、「縦・ホームボタンが上」または
   「縦・ホームボタンが下」を選びます
4. 初回だけ「画面収録」の許可を聞かれるので、許可してください
5. iPadの画面が縦向きになります

### マウスの入り口について

メニューの「マウスは iPadの ◯ から入る」で、Macの画面からiPadへ
マウスカーソルが移動する方向（上下左右のどこから）を選べます。
初期値は「左から」です。

### 元に戻すには

メニューから「横（そのまま）」を選ぶと、通常のSidecar表示に戻ります。

## うまく動かないとき

### 初回に警告が出たとき

「Appleで確認済みの開発元ではないため開けません」
「壊れているため開けません」といった警告が出ることがあります。

このアプリは個人開発のため、Appleの公証（Notarization、年間約$99の
登録が必要な仕組み）を受けていません。そのため、ダウンロードした
実行ファイルに毎回この警告が出ます。**ウイルスではありません。**

対処方法（どちらか）:

- `たてモニ.app` を**右クリック（またはControlキーを押しながらクリック）
  → 「開く」**を選ぶ
- それでも開けない場合は `システム設定 → プライバシーとセキュリティ` を開き、
  一番下に出ている「このまま開く」ボタンを押す

### DisplayLinkなど、他の「拡張ディスプレイ」アプリと一緒に使うとき

DisplayLinkなど他の拡張ディスプレイアプリと同時に使うと、
正しく表示されないことがあります（モニターの接続台数が多いときに
起こりやすいです）。

うまく表示されないときは、次を入れ替えて試してみてください。

- モニターやiPadをつなぐ順番
- アプリを起動する順番

### 画面収録の許可が効かなくなったとき

システム設定の「プライバシーとセキュリティ」→「画面収録」の一覧から
「たてモニ」の行を「－」で一度消し、アプリを開き直して「縦」を選び
直してください。

## 既知の制限

- システム設定のディスプレイ一覧に、画面が1つ多く見えます（仕組み上）
- iPadを直接指で触っても反応しません（映像を貼っているだけのため）
- 内蔵ディスプレイの無いMac（Mac mini / Mac Studio / Mac Pro）向けの
  対策は入れてありますが、そういう環境が手元に無いため
  ★実機での確認はできていません★
- 日本語のみです（多言語化の予定は今のところありません）
- Windows / iPhone / Android 版はありません

## 開発者向け（ソースから自分でビルドしたい方へ）

> ここから下は、`たてモニ.app` をダウンロードして使うだけの方は
> 読む必要がありません。

### ソースコード構成

| ファイル | 役割 |
|---|---|
| `kururin_pa_app.swift` | メニューバーの表示・操作を担当（皮） |
| `kururin_pa_daemon.swift` | 仮想ディスプレイ・映像処理を担当（中身） |
| `6_アプリを作る.command` | ビルド用スクリプト |
| `AppIcon.icns` | アプリアイコン |

### ビルド方法

1. 上の4ファイルを同じフォルダに置きます
2. `6_アプリを作る.command` をダブルクリックします
   - 初回は「開発元を確認できません」という警告が出ることがあります。
     `.command` ファイルを右クリック → 「開く」を選んでください
3. ビルドが終わると、同じフォルダに `たてモニ.app` ができます

### 動作の仕組み（技術的な補足）

- ScreenCaptureKit で仮想ディスプレイを撮影し、90度回転させて
  iPadの上に窓として重ねる方式です（画面そのものは回転させていません）
- 「皮（メニュー・UI）」と「中身（デーモン・映像処理）」の2プロセス構成です
- 心臓の鼓動（heartbeatファイル）による相互監視で、片方が異常終了したら
  もう片方も後を追って終了する仕組みを入れています
