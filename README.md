# たてモニ（たてもに・タテモニ・縦モニ・縦もに・tatemoni）

## 简体中文说明

Tatemoni 是一款免费的 macOS 菜单栏应用，可以把通过「随航」（Sidecar）连接的 iPad 变成 **Mac 的竖屏扩展显示器**。你可以把 Mac 上的文档、网页或聊天窗口拖到 iPad 上。

### 软件功能

- **竖屏显示**：根据 iPad 的摆放方向，选择「Home 键朝上」或「Home 键朝下」。
- **鼠标跨屏**：可设置鼠标从 iPad 的上、下、左、右哪一侧进入。
- **恢复横屏**：选择「横屏（普通随航）」即可切回原来的随航桌面。
- **简体中文界面**：本仓库提供中文菜单、权限提示、错误提示和使用说明。

### 快速上手

1. 横放 iPad，在控制中心锁定屏幕方向，再通过 Mac 的「随航」连接 iPad。
2. 把 iPad 竖起来，打开 Mac 菜单栏里的 Tatemoni，选择对应的竖屏方向。
3. 首次使用时，按提示授权屏幕录制，并退出、重新打开 Tatemoni。然后用 Mac 的鼠标或触控板把窗口拖到竖屏。

中文版构建包要求 macOS 13 或更新版本，支持 Apple Silicon 和 Intel。Mac 与 iPad 需要能够使用随航。竖屏时，macOS 的「显示器」设置会多一块虚拟屏，iPad 的触屏和 Apple Pencil 无法用来操作 Mac 窗口。

[在 GitHub Actions 下载简体中文构建包](https://github.com/Rayen21/tatemoni/actions/workflows/build-zh.yml)（登录 GitHub 后打开成功的构建，在 Artifacts 中下载 `Tatemoni-zh-CN`。）

### ── Sidecarでつないだ iPad を「縦」のサブモニターにする Mac用の無料アプリ

Sidecarで接続したiPadは、いつも横向きの画面にしかなりません。

「たてモニ」は、そのiPadを <strong>縦長のサブモニター（サブディスプレイ）</strong> として使えるようにする、Mac用の無料アプリです。

メニューバーに常駐して、メニューから「縦」を選ぶだけで使えます。

---

## こんなことで困っている方へ

- Sidecarでつないだ **iPadが横向きのままで、縦にならない**
- iPadを**縦置きのサブモニター／サブディスプレイ**として使いたい
- Macの画面を **iPadに縦向きで表示**したい
- **Sidecarの画面を回転**させる方法を探している
- SNSのタイムラインやチャット、縦書きの資料を**縦長の画面**で読みたい
- Mac用の**無料のサブディスプレイアプリ**を探している

このアプリは、そのためのものです。**完全無料・MIT License**です。

## これは何をしているアプリ？

やっていることはシンプルです。

- 縦長の「仮想ディスプレイ（器）」を1枚こしらえる
- 器の中身を画面キャプチャで撮る
- 撮った映像を90度倒して、iPadの画面の上に、枠なし・最前面の真っ黒い窓として貼り付ける

つまり、画面そのものを回転させているのではなく、回した絵を描いて見せている、というのが仕組みです。

そのため、次の2点は仕組み上どうしても直せません。

- システム設定の「ディスプレイ」の一覧に、画面が1つ多く見えます（仮想ディスプレイの分）
- iPadの画面を直接指で触っても反応しません（あくまで映像です）

普段使いには支障ありませんが、正直にお伝えしておきます。

## 使い方

1. `たてモニ.app` を開くと、メニューバーにアイコンが出ます
2. iPadとSidecarで接続します（横向きのまま）
3. メニューバーのアイコンをクリックし、「縦・ホームボタンが上」または「縦・ホームボタンが下」を選びます
4. 初回だけ「画面収録」の許可を聞かれるので、許可してください
5. iPadの画面が縦向きになります

### マウスの入り口について

メニューの「マウスは iPadの ◯ から入る」で、Macの画面からiPadへマウスカーソルが移動する方向（上下左右のどこから）を選べます。初期値は「左から」です。

### 元に戻すには

メニューから「横（そのまま）」を選ぶと、通常のSidecar表示に戻ります。

## うまく動かないとき

### 初回に警告が出たとき

「Appleで確認済みの開発元ではないため開けません」「壊れているため開けません」といった警告が出ることがあります。

このアプリは個人開発のため、Appleの公証（Notarization、年間約$99の登録が必要な仕組み）を受けていません。そのため、ダウンロードした実行ファイルに毎回この警告が出ます。

**ウイルスではありません。**

対処方法（どちらか）:

- `たてモニ.app` を <strong>右クリック（またはControlキーを押しながらクリック）→「開く」</strong> を選ぶ
- それでも開けない場合は **システム設定 → プライバシーとセキュリティ** を開き、一番下に出ている「このまま開く」ボタンを押す

### DisplayLinkなど、他の「拡張ディスプレイ」アプリと一緒に使うとき

DisplayLinkなど他の拡張ディスプレイアプリと同時に使うと、正しく表示されないことがあります（モニターの接続台数が多いときに起こりやすいです）。

うまく表示されないときは、次を入れ替えて試してみてください。

- モニターやiPadをつなぐ順番
- アプリを起動する順番

### 画面収録の許可が効かなくなったとき

システム設定の「プライバシーとセキュリティ」→「画面収録」の一覧から「たてモニ」の行を「－」で一度消し、アプリを開き直して「縦」を選び直してください。

## よくある質問

**Q. 本当に無料ですか？**
完全に無料です。MITライセンスで公開しているので、中身を見るのも、改造して使うのも自由です。

**Q. ウイルスではありませんか？**
ウイルスではありません。Appleの公証を受けていないために警告が出るだけで、ソースコードはすべて公開しています。

**Q. Windows / iPhone / Android 版はありますか？**
Mac版のみです。申し訳ありません。

**Q. iPadを指で触っても反応しません**
仕組み上の制限です。マウスやトラックパッドは今までどおり使えます。

## 開発者向け（ソースから自分でビルドしたい方へ）

ここから下は、`tatemoni.app` をダウンロードして使うだけの方は読む必要がありません。

### ソースコード構成

| ファイル | 役割 |
|---------|------|
| `kururin_pa_app.swift` | メニューバーの表示・操作を担当（皮） |
| `kururin_pa_daemon.swift` | 仮想ディスプレイ・映像処理を担当（中身） |
| `6_アプリを作る.command` | ビルド用スクリプト |
| `AppIcon.icns` | アプリアイコン |

### ビルド方法

1. 上の4ファイルを同じフォルダに置きます
2. `6_アプリを作る.command` をダブルクリックします（初回は「開発元を確認できません」という警告が出ることがあります。`.command` ファイルを右クリック →「開く」を選んでください）
3. ビルドが終わると、同じフォルダに `たてモニ.app` ができます

### 動作の仕組み（技術的な補足）

- ScreenCaptureKit で仮想ディスプレイを撮影し、90度回転させて iPad の上に窓として重ねる方式です（画面そのものは回転させていません）
- 「皮（メニュー・UI）」と「中身（デーモン・映像処理）」の2プロセス構成です
- 心臓の鼓動（heartbeatファイル）による相互監視で、片方が異常終了したらもう片方も後を追って終了する仕組みを入れています
